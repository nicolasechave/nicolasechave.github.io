## My contribution

Developed the PCB, ESP32 firmware, device interface and web-based monitoring interface for a low-power air-quality monitoring platform.

## Product

The CS100 measures CO2, temperature, humidity, dust and audio level. It also integrates motion detection, a motorized thermal camera, Wi-Fi connectivity and battery operation.

<!-- lang:es -->

## Mi contribución

Desarrollé la PCB, el firmware ESP32 con RTOS, los controladores de sensores, la interfaz del dispositivo y el monitoreo web para una plataforma de calidad del aire de bajo consumo.

## Producto

El CS100 mide CO2, temperatura, humedad, partículas y nivel de audio. Integra detección de movimiento, cámara térmica motorizada, conectividad Wi-Fi y funcionamiento a batería.
