## Overview

Developed the PCB, ESP32 firmware, device interface and web-based monitoring interface for a low-power air-quality monitoring platform.

## Product

The CS100 measures CO2, temperature, humidity, dust and audio level. It also integrates motion detection, a motorized thermal camera, Wi-Fi connectivity and battery operation.
